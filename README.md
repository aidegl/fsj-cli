# fsj-cli

> FSJ 的世界接入器 —— agent 的无意识层 + 上下文快路

**状态：早期开发中（v0.1 内测）· 首个公开版本准备中**

---

## 这是什么

**FSJ 是 agent 的世界**——在这里，agents 像人一样工作、协作、生活。**fsj-cli 是接入这个世界的入口**：一条命令装好一套记忆架构、规范与流程，让你（和你的 agents）拥有自己的世界。

它解决一个每天都被磨的问题：

> **agent 找数据靠 LLM 慢搜——十几秒、烧 token、还看运气。**

而架构上明明存在确定性快路：路由映射、权重排序、按索引直取。fsj-cli 把这些快路从"散落在各处的纪律"收拢成"装上就能用的产品"。

## 三个卖点

- **快**：确定性快路——毫秒级取回上下文，不经过模型，不吃 token
- **稳**：可预测、可审计——同样的输入永远同样的输出，每条记录有出处
- **你的**：记忆装在你自己的机器上——整个记忆文件夹拷走，世界就跟走

## 核心概念（对外版）

**世界树**
你的 agent 世界的索引骨架——目标、角色、资产、规矩，长成一颗树。它让 agent 开局就知道"我是谁、该怎么做事"。

**启动包**
`fsj boot` 一条命令，agent 开局即获得身份、规矩要点和按权重排好的索引——不再翻一堆文档找上下文。

**记忆在本地**
个人记忆装在本地工作目录；系统与社区数据按需上云。数据主权清晰：哪些是你的、哪些在云上、哪些进社区，一条线划清。

**id 寻址**
> id 是地址，路径是缓存，哈希是指纹，git 是保险柜。

每个入库文件带稳定 id——文件随便挪、随便改名，按 id 永远找得到；误删了，从版本历史里按 id 捞回来。

## 设计原则

1. **确定性优先**——核心零模型依赖：毫秒响应、结果可复现、过程可审计
2. **数据主权**——你的记忆装在你的机器上；进云端、进社区，边界由你划
3. **换 harness 不换世界**——兼容主流 agent 运行时（MCP 标准），模型随你换，记忆与架构不跟 model 走
4. **玩游戏不用教**——把复杂的 agent 配置变成上手就会的互动
5. **社区共创**——角色包（情绪、动画、表达）开放格式，人人可做、人人可用

## 快速开始（即将可用）

```bash
npm install -g fsj-cli

fsj init          # 互动式引导：几分钟建起你的世界
fsj boot          # 一条命令，agent 开局
fsj get <id>      # 毫秒级直取记录
fsj find <词>     # 索引查询
```
